identity_unavailable

Identity Unavailable

503 Service Unavailable

Returned when Ferra cannot verify a credential because the identity source is unavailable: the identity provider's key set could not be fetched and no fresh key is cached, or an API key lookup failed. The same type, title and detail answer both, so the cause is not visible on the wire. No Retry-After is sent; retry later. New in v0.12.0.

Example RFC 7807 body

{
  "type":   "https://ferra.rs/errors/identity_unavailable",
  "title":  "Identity Unavailable",
  "status": 503,
  "detail": "the credential could not be verified; retry later"
}
