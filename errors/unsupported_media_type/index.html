unsupported_media_type

Unsupported Media Type

415 Unsupported Media Type

Returned when a write request (POST or PUT) carries a body that is not declared as JSON — a missing Content-Type header, or a media type other than application/json (for example text/plain or application/x-www-form-urlencoded). Nothing is written. New in v0.9.0.

415 vs 400 and 422. A 415 is about the declared type of the body, decided from the Content-Type header alone. A body declared as JSON that does not parse is a 400, and a JSON body with an unknown field or a failed validation rule is a 422 validation_failed.

After authorization. The media type is checked after the authorization checkpoint: a caller who is not allowed to perform the operation receives 401, 403 or 404 without learning which body type the route expects. The detail field is the constant literal shown below.

Example RFC 7807 body

{
  "type":   "https://ferra.rs/errors/unsupported_media_type",
  "title":  "Unsupported Media Type",
  "status": 415,
  "detail": "the request body must be JSON: send `Content-Type: application/json`"
}
