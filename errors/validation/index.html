validation

Validation Error

400 Bad Request

Returned when an inbound JSON body fails to parse, or when a path parameter (e.g. an Id) cannot be deserialised. The errors.errors list holds one entry with field "body" (code invalid_json) or "id" (code invalid_path_param), depending on which extractor rejected the request. The same type is also returned for a rejected collection query — a filter or sort on a field that does not allow it, a descending sort combined with a cursor, or cursor together with page — with a detail that names the problem and no errors member.

For rule-constraint failures on a valid body (e.g. #[field(min_length = 1)]), see validation_failed (422).

Example RFC 7807 body — malformed JSON

{
  "type":   "https://ferra.rs/errors/validation",
  "title":  "Validation Error",
  "status": 400,
  "detail": "validation failed",
  "errors": {
    "errors": [
      { "field": "body", "code": "invalid_json", "message": "expected `,` or `}` at line 1 column 14" }
    ]
  }
}
