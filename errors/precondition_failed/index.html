precondition_failed

Precondition Failed

412 Precondition Failed

Returned when a PUT, PATCH, DELETE or restore carries an If-Match or If-None-Match condition that does not hold on the row: the tag is no longer the row's (someone else wrote it since you read it), a weak tag was sent to If-Match, If-None-Match names the row's tag or is *, or the header is not a list of entity tags (or lists more than 32). The row is unchanged. Read the row again, take its new ETag, and decide whether to send your change again. The detail is one fixed text for every cause: it echoes nothing you sent and names no current tag, and the response carries no ETag. A row you may not see is a not_found (404) whatever the header, and a wrong Content-Type is a unsupported_media_type (415), both before this one. New in v0.14.0.

Example RFC 7807 body

{
  "type":   "https://ferra.rs/errors/precondition_failed",
  "title":  "Precondition Failed",
  "status": 412,
  "detail": "an `If-Match` or `If-None-Match` condition of the request is not met; read the row again and retry"
}
